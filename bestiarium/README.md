# Bestiarium

Jeder Eintrag liegt als eigene JSON-Datei unter `daten/` und muss dem
[Schema](schema.json) entsprechen. Einträge kennzeichnen ihren Status als
`bestätigt` oder `Vorschlag`.

Alle Namen eines Eintrags sind gleichberechtigt; es gibt kein bevorzugtes
Anzeigenamenfeld. Dasselbe Wesen unter einem anderen Namen erhält dennoch einen
eigenen Haupteintrag und eine eigene Beschreibung. Namen, Machtstufen und
Kernwerte werden nicht vereinheitlicht oder stillschweigend aus Quellen
abgeleitet.
