# Bestiariumseinträge

Lege hier eine JSON-Datei pro Haupteintrag ab. Neue Einträge haben zunächst den
Status `Vorschlag`. Es gibt noch keine aus dem Notion-Export automatisch
übernommenen Einträge: die Exportstruktur enthält nicht die beschlossenen
Kernwerte und darf nicht ohne inhaltliche Prüfung in das neue Schema gemappt
werden.
